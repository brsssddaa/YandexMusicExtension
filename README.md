# YandexMusicExtension

В веб-версии плеер состоит из двух частей: **интерфейс в браузере (клиент)** и **файловое хранилище (CDN-сервер)**. Расширение встаёт между ними прямо в оперативной памяти браузера.

```mermaid
sequenceDiagram
    autonumber
    actor User as Пользователь
    participant Page as Страница / Плеер (JS)
    participant Ext as Расширение (Инжектор)
    participant API as Сервер API Яндекса
    participant CDN as Хранилище треков (CDN)

    User->>Page: Нажимает "Play" на треке
    Page->>API: Запрос статуса аккаунта (/account/status)
    API-->>Page: Ответ: { plus: false, ads_enabled: true }
    
    Note over Ext,Page: Расширение перехватывает ответ в браузере!
    Ext->>Page: Подмена ответа: { plus: true, ads_enabled: false, quality: "hq" }
    
    Page->>Page: Отключает таймер рекламы и включает режим HQ в плеере
    Page->>API: Запрос ссылки на трек с параметром &hq=1 (320 kbps)
    API-->>Page: Ссылка на аудиопоток CDN (хеш-ссылка)
    Page->>CDN: Загрузка аудиофайла (MP3 320 kbps)
    CDN-->>Page: Поток данных трека
    Page->>User: Воспроизведение чистого звука без рекламы
```

---

## Возможности расширения

* **Высокое качество звука (HQ 320 kbps):** автоматическая разблокировка и передача флага `quality: "hq"` в плеер для загрузки чистого аудиопотока 320 kbps с официального CDN.
* **Блокировка аудиорекламы:** нейтрализация таймеров рекламных вставок между треками.
* **Снятие лимита на переключение:** свободный пропуск треков без всплывающих окон с предложением оформить подписку.
* **Удаление навязчивых баннеров:** очистка интерфейса веб-плеера от блокирующих промо-плашек.
* **Непрерывное воспроизведение:** предотвращение автоматической паузы («Вы ещё слушаете?»).
* **Мобильная адаптация:** автоматическая оптимизация интерфейса веб-плеера под экраны смартфонов.

## Установка расширения

### Для ПК

Поддерживаются любые Chromium-браузеры (**Google Chrome**, **Brave**, **Яндекс Браузер**, **Microsoft Edge**, **Opera**).

1. Скачайте архив репозитория (кнопка **Code** ➔ **Download ZIP**) или склонируйте его:
   ```bash
   git clone https://github.com/brsssddaa/YandexMusicExtension.git
   ```
2. Если скачали `.zip`, распакуйте архив в удобную папку.
3. Откройте страницу управления расширениями в браузере:
   * **Chrome:** `chrome://extensions`
   * **Brave:** `brave://extensions`
   * **Edge:** `edge://extensions`
   * **Яндекс Браузер:** `browser://tune`
4. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
5. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
6. Выберите папку с распакованным расширением.
7. Откройте [music.yandex.ru](https://music.yandex.ru/) и наслаждайтесь любимой музыкой!

### Для телефона

> **Обратите внимание:** Стандартный мобильный Google Chrome не поддерживает установку расширений, а в обычном Firefox для Android разработчики заблокировали установку сторонних файлов (там доступен только фиксированный список «Рекомендованных» дополнений).  
> Поэтому на телефоне рекомендуется использовать браузеры на базе Chromium с прямой поддержкой расширений из ZIP-файлов (**Kiwi Browser** или **Lemur Browser**).

#### Где скачать браузер для телефона:

* **Kiwi Browser (Рекомендуется):**
  * [Официальный GitHub релизов (скачать APK)](https://github.com/kiwibrowser/src.next/releases) *(для большинства смартфонов подходит файл `com.kiwibrowser.browser-arm64-...-github.apk`)*
  * [Зеркало на Uptodown](https://kiwi-browser.ru.uptodown.com/android)
* **Lemur Browser (Доступен в Google Play):**
  * [Скачать в Google Play](https://play.google.com/store/apps/details?id=com.lemurbrowser.exts) *(отличная альтернатива с поддержкой расширений Chrome)*

#### Инструкция по установке (на примере Kiwi Browser / Lemur Browser):
1. Скачайте архив репозитория на телефон (кнопка **Code** ➔ **Download ZIP** вверху этой страницы).
2. Откройте **Kiwi Browser** (или **Lemur Browser**).
3. Нажмите меню (три точки) ➔ **«Расширения»** (или введите в адресную строку `chrome://extensions`).
4. Включите тумблер **«Режим разработчика»** (Developer mode).
5. Нажмите кнопку **«+ (from .zip/.crx/.user.js)»**.
6. Выберите скачанный `.zip` архив из папки «Загрузки» (Download).
7. Откройте [music.yandex.ru](https://music.yandex.ru/) — плеер готов к работе без ограничений и рекламы!
